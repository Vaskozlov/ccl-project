# CCL-project

## Описание

В рамках проекта был разработан язык программирования AstLang с интерпретатором, написанным на C++.
Интерпретатор выполняет оптимизации на этапе разбора -- константные выражения вычисляются заранее, что уменьшает количество операций во время выполнения.
Особенность проекта в том, что реализовано несколько алгоритмов парсинга программ: LL(1), LR(1), GLR, GLL.
Конфигурация парсера и лексического анализатора задается в специальном файле, что обеспечивает быструю настройку.

## Синтаксис

```astlang
// Объявление переменных
var x = 42;
var name = "AstLang";

// Арифметические операции
var result = (10 + 5) * 2;

// Условные конструкции
if x > 20 {
    println("x больше 20");
} elif x == 20 {
    println("x равно 20");
} else {
    println("x меньше 20");
}

// Циклы
var i = 0;
while i < 5 {
    println(i);
    i = i + 1;
}

// Функции
def greet(string name) -> string {
    return "Привет, " + name + "!";
}

println(greet("Мир"));
```

## Поддерживаемые конструкции

### Объявление и присваивание переменных

```astlang
// Без указания типа (тип выводится)
var x = 42;
var name = "AstLang";

// С явным указанием типа
var count: int = 10;
var ratio: double = 3.14;

// Присваивание
x = x + 1;
```

### Условные конструкции

```astlang
if condition {
    // ...
} elif other_condition {
    // ...
} else {
    // ...
}
```

Блоков `elif` и `else` может не быть. Блоков `elif` может быть несколько.

### Циклы

```astlang
var i = 0;
while i < 10 {
    println(i);
    i = i + 1;
}
```

### Функции

```astlang
// Определение функции с указанием типов аргументов и возвращаемого типа
def add(int a, int b) -> int {
    return a + b;
}

// Функция без возвращаемого значения
def greet(string name) {
    println("Hello, " + name);
}

// Вызов функции
var result = add(3, 4);
greet("World");
```

Ключевое слово `return` может использоваться с выражением или без него:

```astlang
return 42;    // вернуть значение
return;       // выйти из функции
```

### Массивы

```astlang
var arr = [1, 2 + 3, 5 * 4];
```

### Доступ к полям и вызов методов

```astlang
// Доступ к полю
var x = vec.x;

// Вызов метода
var len = "hello".length();
```

## Выражения

Приоритет операторов от низкого к высокому:

| Приоритет | Категория | Операторы | Пример |
|-----------|-----------|-----------|--------|
| 1 | Присваивание | `=` | `x = 10` |
| 2 | Логическое ИЛИ | `\|\|` | `a \|\| b` |
| 3 | Логическое И | `&&` | `a && b` |
| 4 | Поразрядное ИЛИ | `\|` | `a \| b` |
| 5 | Поразрядное XOR | `^` | `a ^ b` |
| 6 | Поразрядное И | `&` | `a & b` |
| 7 | Равенство | `==`, `!=` | `a == b`, `a != b` |
| 8 | Сравнение | `<`, `>`, `<=`, `>=` | `a < b`, `a >= b` |
| 9 | Сложение / вычитание | `+`, `-` | `a + b`, `a - b` |
| 10 | Умножение / деление | `*`, `/` | `a * b`, `a / b` |
| 11 | Остаток от деления | `%` | `a % b` |
| 12 | Унарные | `+`, `-` | `+x`, `-x` |

Литералы и основные значения:

```astlang
// Числа
var int_val = 42;
var float_val = 3.14;

// Строки
var text = "Hello, World!";

// Логические значения
var flag = true;
var empty = false;

// Массивы
var numbers = [1, 2, 3];

// Вызовы функций
var now = timeNs();

// Вложенные выражения в скобках
var expr = (10 + 5) * 2;
```

## Оптимизации

Интерпретатор AstLang выполняет оптимизацию **константных выражений** на этапе разбора (constant folding).
Все выражения, значения которых известны заранее, вычисляются до начала выполнения -- это уменьшает количество операций во время работы программы.

**Поддерживаемые оптимизации:**

| Тип | Операции | Пример | Результат |
|-----|----------|--------|-----------|
| Арифметика | `+`, `-`, `*`, `/`, `%` | `10 + 5` | `15` |
| Сравнение | `<`, `>`, `<=`, `>=`, `==`, `!=` | `10 < 5` | `false` |
| Логические | `&&`, `\|\|` | `true \|\| false` | `true` |
| Поразрядные | `&`, `\|`, `^` | `7 & 3` | `3` |
| Унарные | `+`, `-` | `-42` | `-42` |
| Конвертация | `int()`, `uint()`, `float()`, `double()`, `bool()`, `string()` | `int(3.14)` | `3` |

Пример демонстрации оптимизаций:

```astlang
// Все эти выражения вычисляются до начала выполнения
var x = 2 + 3;           // --&gt; 5
var y = 10 < 5;           // --&gt; false
var z = -42;             // --&gt; -42
var w = "hello" + " world"; // --&gt; "hello world"
var a = true && false;    // --&gt; false
var b = true || false;    // --&gt; true
var c = 7 * 3;           // --&gt; 21
var e = int(3.14);       // --&gt; 3
var f = bool(1);         // --&gt; true
var g = string(42);      // --&gt; "42"
```

Интерпретатор выводит:

```
5
false
-42
hello world
false
true
21
3
true
42
```

Оптимизированное дерево разбора для `println(5 + 5)`:

```
└──NodeSequence-FUNCTION_CALL
       ├──-IDENTIFIER: println
       └──NodeSequence-FACTOR
              └──-CONSTANT: 10
```

Видно, что выражение `5 + 5` заменено на константу `10` ещё до выполнения программы.
